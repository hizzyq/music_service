## 1. Архитектурная концепция: Почему именно так

Главный вопрос любого преподавателя по веб-разработке:  
> *"Зачем вы подключили MinIO/S3 и JWT? Почему не загружать файл на Rails и не отдавать его обычным `send_file`?"*

### Проблема 1. Истощение пула потоков (Thread Starvation) при обычном стриминге
Веб-сервер Rails (Puma) работает в модели пула потоков (стандартно 3–16 потоков).  
- Если отдавать 4-минутный MP3 или 30-мегабайтный FLAC через контроллер Rails, соединение с клиентом остается открытым все время прослушивания и буферизации.
- При пуле из 16 потоков всего 16 одновременных слушателей полностью парализуют бэкенд: 17-й пользователь не сможет даже открыть главную страницу.

### Проблема 2. Двойная перекачка трафика при Multipart Upload
- Если клиент загружает трек через Rails (`POST /tracks` с файлом в `multipart/form-data`), сервер сначала сохраняет файл во временный файл ОС (`/tmp`), а затем отдельным сетевым вызовом загружает его в хранилище. Это создает двукратный сетевой оверхед и пики по оперативной памяти.

### Решение: Архитектура Presigned URLs (Zero-I/O Backend)
```
                                +-----------------------------+
                                |      React Frontend         |
                                |     (localhost:5173)        |
                                +-----------------------------+
                                   /           |             \
            1. POST /auth/login   /            |              \  4. Direct PUT Upload
            2. GET /tracks       /             | 3. GET /stream\    (Presigned PUT)
                                v              v                v
                 +-------------------------------+       +--------------------+
                 |           Rails API           |       |     MinIO (S3)     |
                 |       (localhost:3000)        |       |  (localhost:9000)  |
                 +-------------------------------+       +--------------------+
                   |                 ^     |                |              |
    CRUD / Records |     Temp file / |     | Generate SigV4 |              | 5. Stream
                   v     Metadata    |     v URLs           |                 Range bytes
                 +---------------------+                    |                 (HTTP 206)
                 |     PostgreSQL      |                    +--------------->[ Browser ]
                 |  (localhost:5432)   |                                     [ Audiotag]
                 +---------------------+
```

1. **Direct Stream:** Rails проверяет права пользователя по JWT и формирует URL к MinIO, криптографически подписанный по протоколу **AWS Signature V4** с коротким TTL (15 минут). Клиент качает байты **напрямую из MinIO**, минуя Rails.
2. **Direct Upload:** Клиент запрашивает ссылку для заливки, загружает бинарный файл напрямую в MinIO через HTTP `PUT`, а бэкенду отправляет только легкий JSON `{ file_key: "..." }`.
3. **Range Requests (RFC 7233):** Браузер запрашивает чанки байт (`Range: bytes=0-1000000`). MinIO отвечает кодом `206 Partial Content`. Перемотка работает мгновенно.

## 3. Эволюция проекта: Что БЫЛО vs Что СТАЛО

| Аспект | Что БЫЛО | Что СТАЛО | Зачем и как это сделано |
| :--- | :--- | :--- | :--- |
| **Безопасность ссылок на стрим** | `TracksController#index` генерировал `stream_url` для каждого трека в списке. Неавторизованный пользователь мог слушать любые треки в обход проверки прав. | `stream_url` удален из `index` и `show`. Ссылка выдается **строго** через защищенный эндпоинт `GET /tracks/:id/stream` с проверкой JWT. | Устранена критическая уязвимость обхода авторизации; убраны тяжелые вызовы SigV4 на каждый показ списка. |
| **Поддерживаемые форматы** | Только `.mp3` через библиотеку `ruby-mp3info`. При попытке загрузить FLAC или M4A сервис падал с ошибкой. | **MP3, FLAC, M4A (AAC), WAV, OGG**. | Переписан `TrackMetadataExtractor` на базе `ffprobe`. Теперь читаются теги любого формата. |
| **Массовая загрузка (Batch Upload)** | Только 1 файл за раз, модалка блокировалась. | **Мультивыбор файлов (`multiple`), прогресс по каждому файлу, пакетная заливка в S3 и распознавание**. | Можно за один раз закинуть весь альбом или дискографию. |
| **Удаление треков** | Удаление отсутствовало. | **Эндпоинт `DELETE /admin/tracks/:id`** с каскадной очисткой аудиофайла и обложки из бакета MinIO. Кнопка корзины для админа в каталоге. | Возможность убирать ненужные треки без накопления файлов-сирот в S3. |
| **Избранное (Favorites)** | Отсутствовало. | **1-клик добавление в избранное (сердечко)** на каждой строке и в плеере (`POST /favorites/:track_id`). Быстрая синхронизация статуса. | Удобный доступ к любимым трекам. |
| **Обложки альбомов** | Обложки не поддерживались, отображалась пустая иконка. | **Автоматическое извлечение встроенной обложки** из ID3/FLAC метаданных через `ffmpeg -an -vcodec copy`, заливка в MinIO (`covers/*.jpg`) и отдача по Presigned URL. | Альбомы и треки автоматически получают реальные обложки прямо из загруженного файла. |
| **Интерактивная звуковая волна (Waveform)** | Отсутствовала (был только плоский ползунок `<input type="range">`). | `ffmpeg` даунсемплит звук до 1000 Гц и рассчитывает **100 нормализованных пиковых амплитуд**, сохраняя их в `tracks.waveform` (`jsonb`). В плеере отрисован интерактивный кликабельный скраббер, плюс мини-волна в списке треков. | Визуальное отображение трека как в SoundCloud / Spotify; перемотка кликом по любому участку звуковой волны. |
| **Плейлисты и история** | Отсутствовали. | Сущности `Playlist`, `PlaylistTrack` (связь N-к-M) и `ListeningHistory`. Фронтенд автоматически логирует историю при старте воспроизведения. | Персональные коллекции и журнал прослушанного. |
| **Инициализатор S3** | Файл назывался с опечаткой `r3.rb`. | Переименован в `s3.rb`. | Стандартизация структуры проекта. |
| **Сиды базы данных** | `db/seeds.rb` был пустой. | Написан идемпотентный сид, создающий администратора (`admin@test.com`), слушателя (`listener@test.com`) и демо-трек. | Развертывание с нуля за одну команду `rails db:seed`. |

## 4. Подробный разбор ключевых подсистем

### 4.1. Мультиформатный Media Pipeline (FFmpeg + FFprobe)
Вместо ограниченных Ruby-гемов используется связка `Open3` + `ffprobe` + `ffmpeg`.
1. **Чтение метаданных:**  
   `ffprobe -v quiet -print_format json -show_format -show_streams file.ext` возвращает стандартизированный JSON. Скрипт приводит ключи к нижнему регистру (потому что FLAC пишет `TITLE`, а MP3 — `title`), извлекая название, артиста, альбом, год и длительность.
2. **Экстракция обложки альбома:**  
   Если в медиафайле есть видео-стрим с кодеком `mjpeg` или `png` (встроенная обложка), вызывается:
   ```bash
   ffmpeg -y -i input.audio -an -vcodec copy cover.jpg
   ```
   Файл загружается в MinIO в папку `covers/<uuid>.jpg` с заголовком `Content-Type: image/jpeg`, а его ключ сохраняется в `albums.cover_key`.
3. **Расчет звуковой волны:**
   ```bash
   ffmpeg -i input.audio -ac 1 -filter:a aresample=1000 -f s16le -
   ```
   Аудио преобразуется в одноканальный 16-битный поток PCM с частотой 1000 семплов/сек. Ruby читает его через `raw_pcm.unpack("s*")`, делит на 100 равных корзин (бакетов) и берет максимальную амплитуду в каждой, нормализуя значение в диапазон `0.05 ... 1.0`.

### 4.2. Безопасность и стриминг (Presigned URLs + RFC 7233)
- В модели `Track` метод `stream_url` динамически определяет MIME-тип файла:
  ```ruby
  def content_type
    case File.extname(file_key).downcase
    when ".flac" then "audio/flac"
    when ".m4a"  then "audio/mp4"
    when ".aac"  then "audio/aac"
    when ".wav"  then "audio/wav"
    when ".ogg"  then "audio/ogg"
    else "audio/mpeg"
    end
  end
  ```
- В MinIO включена глобальная отдача CORS:
  `MINIO_API_CORS_ALLOW_ORIGIN: "*"`
- В Rails в `config/initializers/cors.rb` настроена отдача критических заголовков:
  `expose: ["Content-Range", "Accept-Ranges", "Content-Length", "ETag"]`.
  Браузер шлет заголовок `Range: bytes=0-1000`, MinIO отвечает кодом `206 Partial Content`.

### 4.3. Интерактивная звуковая волна (Waveform)
- В базе данных: колонка `waveform` типа `jsonb` со 100 числами от 0.05 до 1.0.
- В компоненте `PlayerBar.tsx`:
  - 100 баров с высотой пропорциональной амплитуде (`Math.max(4, peak * 32) + "px"`).
  - Сыгранная часть подсвечивается неоновым изумрудным градиентом `bg-emerald-400`.
  - Клик в любую точку рассчитывает процент смещения `clickX / totalWidth` и вызывает `audio.currentTime = pct * duration`.

### 4.4. База данных и связи (PostgreSQL ER)
```
  +------------------+         +------------------+         +--------------------+
  |      users       |         |     artists      |         |       albums       |
  +------------------+         +------------------+         +--------------------+
  | id               |         | id               |         | id                 |
  | email (unique)   |         | name             |         | title              |
  | password_digest  |         | bio              |         | release_year       |
  | role (enum)      |         +--------+---------+         | cover_key          |
  +--------+---------+                  |                   | artist_id (FK)     |
           |                   1:N      |                   +---------+----------+
           +---------------+------------+                             | 1:N
           |               |                                          v
           v               v                                +--------------------+
  +----------------+ +---------------------+                |       tracks       |
  |   playlists    | | listening_histories |                +--------------------+
  +----------------+ +---------------------+                | id                 |
  | id             | | id                  |                | title              |
  | name           | | user_id (FK)        |                | duration           |
  | description    | | track_id (FK)       | <------------+ | track_number       |
  | user_id (FK)   | | listened_at         |                | file_key           |
  +-------+--------+ +---------------------+                | album_id (FK)      |
          | 1:N                                             | waveform (jsonb)   |
          v                                                 +---------+----------+
  +-------------------+                                               |
  |  playlist_tracks  |                                               |
  +-------------------+                                               |
  | id                |                                               |
  | playlist_id (FK)  |                                               |
  | track_id (FK)     | ----------------------------------------------+
  | position (int)    |
  +-------------------+
```

### 4.5. Плейлисты, Избранное в 1 клик и История прослушиваний
- **Избранное:** При нажатии на сердечко вызывается `POST /favorites/:track_id`. Бэкенд находит или создает персональный системный плейлист «Избранное» и переключает наличие трека. Эндпоинт `GET /favorites/ids` позволяет фронтенду за 1 запрос подсветить все сердечки.
- **История:** При каждом старте воспроизведения трека фронтенд отправляет `POST /history` с `track_id`, записывая метку времени `listened_at`.

### 4.6. Массовая загрузка и удаление треков с очисткой MinIO
- **Массовая загрузка:** Модальное окно `UploadModal` принимает пачку файлов (`FileList`), последовательно запрашивает Presigned PUT URL для каждого, качает напрямую в MinIO и вызывает обработку метаданных в Rails.
- **Удаление:** Эндпоинт `DELETE /admin/tracks/:id` удаляет запись из базы данных, а затем отправляет команду `S3_CLIENT.delete_object(bucket, track.file_key)` для освобождения места в MinIO. Если альбом опустел, удаляется и сам альбом вместе с его обложкой.

## 5. Карта устраненных инженерных инцидентов и багов

| Симптом проблемы | Первопричина | Инженерное решение |
| :--- | :--- | :--- |
| **`unknown attribute 'waveform' for Track`** | Миграция была применена, но процесс веб-сервера Puma держал старый кэш схемы базы данных в оперативной памяти. | Перезапуск процесса Puma со свежим кэшем схемы ActiveRecord. |
| **Порт 3000 занят** | На машине работал фоновый контейнер OpenWebUI, перехвативший порт 3000. | Контейнер OpenWebUI остановлен по согласованию, стандартный порт 3000 освобожден для Rails Puma. |
| **Утечка стриминговых ссылок** | Метод `track_payload` в `TracksController` генерировал `stream_url` для каждого трека в незащищенном методе `index`. | `stream_url` убран из общей выдачи. Защищенный URL генерируется только по запросу `GET /tracks/:id/stream`. |
| **Падение на FLAC/M4A** | Библиотека `ruby-mp3info` не умеет читать другие контейнеры. | Интеграция `ffprobe` в `TrackMetadataExtractor`, нормализующая любые теги. |
| **Отсутствие обложек** | Поле `cover_key` не заполнялось при загрузке. | Извлечение встроенного арта через `ffmpeg` и автоматическая загрузка в бакет `music/covers/`. |
| **Опечатка в конфигурации** | Инициализатор S3 назван `r3.rb`. | Переименован в `s3.rb`. |
| **Дубликат `upload.ts`** | Неиспользуемый файл дублировал логику `admin.ts`. | Файл удален, логика типизирована в `admin.ts`. |
| **Строгие проверки коллбэков** | Rails 7.1+ требует обязательного наличия экшенов из `before_action :only`. | Изолированы коллбэки между `ApplicationController`, `TracksController` и `Admin::TracksController`. |

## 7. Методичка для идеальной защиты перед преподавателем

### Шаг 1. Концептуальное вступление (30 секунд)
> *"Наш проект — это архитектурно выверенная система с нулевой нагрузкой на поток веб-сервера при передаче медиаконтента (Zero-I/O Backend). Мы разделили обязанности: Rails отвечает за бизнес-логику и безопасность, MinIO отдает аудио по RFC 7233, а FFmpeg строит звуковую волну, извлекает обложки и парсит метаданные."*

### Шаг 2. Живая демонстрация безопасности (Live Demo)
1. **Показ 401 Unauthorized:**
   ```bash
   curl -i http://localhost:3000/tracks/1/stream
   ```
2. **Получение токена:**
   ```bash
   TOKEN=$(curl -s -X POST http://localhost:3000/auth/login \
     -H "Content-Type: application/json" \
     -d '{"email":"admin@test.com","password":"password123"}' | jq -r .token)
   ```
3. **Получение Presigned URL со статусом 200:**
   ```bash
   STREAM_URL=$(curl -s -H "Authorization: Bearer $TOKEN" http://localhost:3000/tracks/1/stream | jq -r .stream_url)
   echo $STREAM_URL
   ```
4. **Демонстрация частичной загрузки (RFC 7233 / HTTP 206):**
   ```bash
   curl -D - -s -o /dev/null -H "Range: bytes=0-1000" "$STREAM_URL"
   ```

### Шаг 3. Демонстрация интерфейса в браузере (http://localhost:5173)
1. Войди под `admin@test.com` / `password123`.
2. Покажи каталог треков с **автоматически извлеченными обложками** и мини-волной.
3. Нажми на **сердечко** у трека — покажи 1-клик добавление в Избранное.
4. Включи трек: покажи, как в нижней панели плеера отображается **интерактивная звуковая волна (Waveform)** с подсветкой текущей позиции.
5. Кликни по звуковой волне — покажи плавную перемотку.
6. Открой **«Мои плейлисты»** и **«История»** — покажи синхронизацию.
7. Нажми **«Загрузить трек»** — выбери сразу несколько файлов (`.flac`, `.mp3`, `.m4a`) и покажи **массовую загрузку** с извлечением обложек и волны.
8. Покажи иконку **корзины** — удали трек и объясни, что файл физически удаляется и из PostgreSQL, и из MinIO.

## 8. Архитектурные и UI/UX усовершенствования («cd ~/music/»)

### 8.1. Ребрендинг и Linux-терминальная эстетика
Проект оформлен в строгом, самобытном хакерском стиле Linux CLI:
- **Фирменный стиль:** Верхняя плашка эмулятора терминала (`tty1`, цветные индикаторы закрытия/сворачивания окна macOS/X11), анимированный курсор командной строки `cd ~/music/`.
- **Neofetch-инфопанель:** В боковом меню отображаются параметры текущей сессии:
  - `OS: Linux/x86_64`
  - `USER: root#admin` (для администратора с подсветкой `sudo mode: active`) либо `user$listener` (для обычного слушателя)
  - `STORE: MinIO [S3]`
- **Команды оболочки в навигации:** Вместо стандартных вкладок используются команды файловой системы:
  - `~/tracks/` — каталог композиций (`$ ls -la ~/music/tracks/`)
  - `~/playlists/` — каталог плейлистов (`$ ls -la ~/playlists/` и `$ mkdir --playlist`)
  - `~/history.log` — журнал прослушиваний (`$ tail -n 50 -f ~/music/history.log`)
  - `$ upload --batch` — массовая загрузка файлов
  - `$ exit` — выход из сессии
- **Бейджи форматов и моноширинная верстка:** Номера треков выравниваются моноширинным форматом (`01`, `02`), а рядом с названиями отображаются метки кодеков (`[FLAC]`, `[M4A]`, `[MP3]`).

### 8.2. Реактивное Live-обновление счетчиков (Optimistic & Reactive UI)
- **Проблема классических MPA/SPA:** При клике на сердечко (добавление в Избранное) счетчик на странице плейлистов или в меню требовал перезагрузки страницы или повторного сетевого запроса.
- **Решение:** Архитектура реактивных хранилищ Zustand (`useFavoritesStore` + `usePlaylistsStore`):
  1. При вызове `toggleFavorite(trackId)` обновляется локальный `Set` идентификаторов избранного.
  2. Хранилище `useFavoritesStore` моментально вызывает метод `usePlaylistsStore.getState().updateTrackCount('Избранное', +1 / -1)`.
  3. В боковом меню бейдж `♥ {favoriteIds.size}` и в каталоге плейлистов счетчик треков карточки «Избранное» перерисовываются **мгновенно на глазах пользователя**, без перезагрузки и без задержки сети.

### 8.3. Безопасность громкости по умолчанию (Acoustic Safety)
- При первом открытии веб-сайта громкость звука **никогда не ставится на максимум (100%)**, чтобы не оглушить пользователя в наушниках.
- Установлено безопасное значение по умолчанию: **60% (`0.6`)**.
- Любое изменение ползунка громкости синхронизируется с `localStorage` браузера (`music_player_volume`) и восстанавливается при последующих заходах.

### 8.4. Динамическое монтирование нижней панели плеера
- **Проблема:** До запуска первого трека внизу экрана висела пустая черная плашка (пустой плеер без контента), съедавшая полезную высоту экрана.
- **Решение:** Компонент `<PlayerBar />` монтируется условно (`{currentTrack && <PlayerBar />}`), а рабочий контейнер страниц переключает паддинг с `pb-0` на `pb-28` плавной CSS-анимацией. До запуска музыки интерфейс выглядит чистым и цельным.

### 8.5. Двухуровневый контроль ролевого доступа (RBAC Security)
- **Frontend-уровень:** Кнопки `$ upload --batch` и иконки удаления (корзина) физически скрыты для роли `listener` (`role: 0`).
- **Backend-уровень:** `Admin::TracksController` защищен строгим фильтром:
  ```ruby
  def require_admin
    render json: { error: "Доступ запрещен: требуются права администратора" }, status: :forbidden unless current_user.admin?
  end
  ```
  Прямые запросы к `/admin/tracks/presign_upload` и `DELETE /admin/tracks/:id` с токеном слушателя возвращают статус **`403 Forbidden`**.
